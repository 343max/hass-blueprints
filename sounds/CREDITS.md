# Thunder samples

Nine thunder recordings cut to ~6 s, loudness-normalised (EBU R128, −16 LUFS,
true peak −1.5 dBTP) and encoded as 192 kbps MP3 for use as Sonos AudioClips by
`blueprints/automation/lightning_thunder.yaml`.

Served via GitHub Pages:
`https://343max.github.io/hass-blueprints/sounds/thunder-01.mp3`

All files were trimmed to the loudest segment, faded in (20 ms) and out (1.2 s).
